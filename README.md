# Cartoon Explainer Remotion Project

This repo contains the render-ready Remotion project for the cartoon explainer video.

## Local Render

```bash
npm install
npm run render
```

The rendered video is written to `renders/cartoon-explainer.mp4`.

## GitHub Render

Open the **Actions** tab, choose **Render Remotion Video**, and run the workflow manually. The MP4 will be available as a workflow artifact.
